# Vantier — Ralph Lauren

Site estático (HTML + CSS + JS), sem build.

```
index.html
assets/css/style.css
assets/js/main.js
assets/img/
vercel.json
```

## Deploy
1. Suba para o GitHub (`git init`, `git add .`, `git commit`, `git push`).
2. Na Vercel: Add New → Project → importe o repositório.
3. Framework Preset: **Other**. Build Command e Output Directory: deixe vazios. Deploy.
